# Сайт дизайнера — варианты для сравнения

Бриф и ответы грилла — [BRIEF.md](BRIEF.md). Это НЕ лок: четыре варианта и
витрина эффектов, чтобы выбрать. Выкладка — только после одобрения.

## Запуск

```bash
npm install --prefix .design/designer
npm run dev --prefix .design/designer
```

Открыть `http://127.0.0.1:5180/` — оглавление со ссылками на всё.

| страница | что это |
|---|---|
| `index.html` | оглавление: чем отличаются варианты, ссылки «как на телефоне» |
| `a.html` | A «Ночной показ» — тёмный, параллакс на каждую работу, лента экранов |
| `b.html` | B «Дневной свет» — светлый, Text Pressure, общий параллакс + Flowing Menu |
| `c.html` | C «Плёнка» — зерно и перфорация, портфолио-лента ведётся скроллом, Image Trail |
| `d.html` | D «Контраст» — тёмный вход, светлая афиша, Oi, Flowing Menu-оглавление |
| `effects.html` | все механики по одной (reactbits у владелицы не открывается) |

Параметры адреса в любом варианте: `?device=phone` — показать телефонную
сцену на компьютере, `?fx=mesh` (по умолчанию) — лёгкий градиент, меняющийся
при прокрутке, `?fx=shader` — прежний живой шейдер, `?fx=lite` — его кадр.
Внизу страницы есть переключатель «градиент / шейдер».

## Что откуда

- **Ноутбук** — `src/shared/DeviceHero.tsx`, по мотивам aceternity MacbookScroll.
  Крышка размером с окно, уменьшена `scale3d` — поэтому после раскрытия тот же
  холст остаётся фоном, второй WebGL-сцены нет. Разбор — в шапке файла.
- **Градиент** — `src/shared/Mesh.tsx`: фон по умолчанию (её правка «шейдер
  тяжёлый»). Пятна её цветов на своих слоях, прокрутка двигает только
  transform/opacity. Вес страницы: 1,9 МБ против 3 МБ у шейдера, JS 462 КБ
  против 1586 КБ (без сжатия, `scripts/weight.mjs`).
- **Цены** — `src/shared/Chat.tsx`: переписка в телеграме её словами.
- **Шейдер** (для сравнения) — `src/shared/Shader.tsx` + `ShaderCanvas.tsx`, её настройка с
  shadergradient.co один в один. three.js грузится лениво: лёгкий режим его не
  скачивает. Карты освещения — `public/hdr` (локально, без github.io).
- **Подпись** — `src/shared/Signature.tsx`, из `фото/signature-arisheniaa.html`.
- **Параллакс** — `src/fx/Parallax.tsx` (aceternity parallax-hero-images +
  наклон телефона и скролл).
- **reactbits** (MIT) — `src/fx/CircularGallery.tsx`, `FlowingMenu.tsx`,
  `ImageTrail.tsx`, `TextPressure.tsx`. Правки записаны в шапке каждого.
- **Тексты** — `src/shared/copy.ts`; «Обо мне» и цены — черновик, цифры «—».
- **Работы** — `src/shared/works.ts`; кадры в `public/works`. Приглашение снято
  `scripts/capture-invite.mjs` с локальной копии `Приглашения/sayt`.

## На сайте (с 5 октября 2026)

Вариант A — главная arisheniaa.ru. `npm run build` собирает только её
(`index.html` → вариант A) и `public/`; так сайт собирает сервер
(`server/build.sh`, каталог `site/root/`). Все варианты для сравнения и
артефакта на claude.ai — `npm run build:variants` (оглавление —
`variants.html`). Проверка под заголовками сервера — `scripts/csp-check.mjs`,
боевого сайта — `scripts/live-check.mjs`. Выкладка — пуш в `master`
(сторож на сервере, DEPLOY.md).

## Вариант A — выбран (4 октября 2026)

Правки после выбора — BRIEF.md, раздел «Выбор: вариант A». Новые части:
`Lightbox.tsx` (скрин крупно по нажатию), `Progressive.tsx` (блоки ниже
первого экрана достраиваются в паузах браузера), `CalmVeil.tsx` (общее
затемнение вместо подложек блоков). `Seam.tsx` (волны на стыках) и
`PhoneFan.tsx` (веер) из A убраны её правками, файлы оставлены.

Третий раунд (5 октября): фон — один градиент без волн на стыках; видимых
заголовков разделов нет; переписка цен по высоте считается от окна и
влезает в Full HD и при 100 %, и при 125 % масштаба Windows (окно ~1536×730);
у сообщений острые хвостики как у SMS; в контактах снова строка ссылок.

Пятый раунд (5 октября): блок цен убран, работы стали одним экраном из
трёх услуг (`Services.tsx`) — раскрытие на весь экран «под стекло»,
скрин крупно с подписью и ссылкой, крестик назад по шагам. Описания
услуг и многостраничник — черновик.

Четвёртый раунд (5 октября): заголовки «Работы» и «Обо мне» вернулись;
Элегия — последней; приглашение — её скриншоты, её текст и ссылка на
«дежурную» копию (`public/invite/`, на компьютере — в рамке телефона с
пометкой); слоты концептов убраны; рамка фото и справа; её тексты «Обо
мне» и вопроса в чате; жёлтая звёздочка у ника; финальная фраза меньше.

Шестой раунд (5 октября, после Ф87): «на десктопе верни прежнюю версию,
мобильную не трогай; на десктопе оставь только ноутбук — чтобы клавиатура
не отделялась от экрана». На компьютере из Ф87 остался один наезд камеры на
ноутбук целиком (`zoomWhole`); всё остальное — как до Ф87: эталон Full HD
(`fluid.css`) не подключён, раскрытая услуга — прежнее кольцо кадров, у
услуг прежние наборы кадров (`desk` в `works.ts`), фон без дрейфа и смены
оттенка, подсказка «листайте» снова есть. Телефон — ровно как в Ф87.

Седьмой раунд (5 октября, Ф89):
- раскрытая услуга — кадры ровно вокруг карточки на компьютере и телефоне:
  их уводил вверх сдвиг от прокрутки (в неподвижном слое он выключен,
  `drift` в Parallax), а на компьютере слоты задаются центром кадра,
  симметрично от середины окна;
- сайт Алёны — снова девять страниц с ноутбука и десятая: блок обучения с
  пластинкой (`toto-plastinka`); приглашение — снова двенадцать кадров,
  на компьютере по три столбца телефонов с каждой стороны;
- «Многостраничник» — пока концепции редизайнов пяти ресторанов
  (`scripts/capture-restaurants.mjs`, плашка «не для публикации» на кадрах
  скрыта, в подписи — «концепция»);
- надписи «листайте» нет; фон живой и на компьютере;
- на телефоне страница не водится вбок: свечение за фото «Обо мне»
  расширяло её до 517 px при экране 390 (`overflow-x: clip` у `.content`).

Восьмой раунд (5 октября, Ф90): в просмотре скрина крестик и стрелка —
ровно друг под другом: крестик услуги под просмотром прячется (просвечивал
вторым значком), у всех круглых кнопок один отступ от края (`--ctl-edge`),
значки — линиями (`CtlIcon` в ui.tsx), а не буквами «×» и «›». На телефоне
во вступлении снова ноутбук, тоже целиком, без отрыва экрана; подпись на
его экране не шире 86% окна (иначе обрезалась на портретном экране).

Замеры (`scripts/perf.mjs`, `scripts/cold.mjs`, Full HD):
- прокрутка после облегчения — 60 к/с, худший кадр 17 мс и на первом
  проходе (было: провалы 133–483 мс);
- холодная загрузка с процессором, замедленным в 4 раза: после паузы в 3 с
  прокрутка 60 к/с, худший кадр 17 мс; самая долгая задача при загрузке —
  0,56 с (при 4× замедлении), раньше — один кадр 1,4–1,5 с.

## Скрипты

| команда | что делает |
|---|---|
| `node scripts/shots.mjs a,b 1440,390` | снимки по кадрам скролла в `_shots/` (нужен dev-сервер) |
| `node scripts/sheet.mjs a-1440` | контактный лист снимков |
| `node scripts/pages.mjs` | снимки оглавления и витрины |
| `node scripts/check-reel.mjs` | проверка, что подпись ленты C идёт за кадром |
| `node scripts/poster.mjs` | кадр шейдера для лёгкого режима |
| `node scripts/capture-invite.mjs` | кадры приглашения для портфолио |
| `python scripts/cutout.py` | фото «Обо мне» вырезкой с чёрной рамкой (нужен `pip install "rembg[cpu]"`) |
| `node scripts/about.mjs` | снимок раздела «Обо мне» во всех вариантах |
| `node scripts/perf.mjs a` | плавность прокрутки с выключением слоёв по одному |
| `node scripts/cold.mjs a` | холодная загрузка сборки (нужен `vite preview` на 5181) |
| `node scripts/check-lightbox.mjs` | проверка просмотра скрина крупно |
| `node scripts/invite-demo.mjs` | «дежурное» приглашение без имён и мест в `public/invite/` (из `Приглашения/sayt`) |
| `node scripts/invite-check.mjs` | проверка приглашения: рамка телефона на компьютере, телефон, «Обо мне» |
| `node scripts/capture-restaurants.mjs` | кадры концепций ресторанов для «Многостраничника» (из `Редизайн сайтов/showcase`) |
| `node scripts/works-shots.mjs имя` | снимки экранов всех работ (раскладка скринов) |
| `node scripts/services-check.mjs` | блок услуг: колонки → услуга → скрин с подписью → крестик/Esc по шагам |
| `node scripts/fit.mjs` | влезает ли переписка в окно на четырёх размерах (нужен `vite preview` на 5181) |
| `node scripts/seams-check.mjs` | кадры на бывших стыках блоков, хвостики сообщений, финал |
| `node scripts/fix-fffd.mjs dist/assets` | подготовка сборки к публикации на claude.ai |

Снимки делаются через видеокарту (ANGLE/D3D11): на программном рендере шейдер
во весь экран не успевает отдать кадр.

## Известное и отложенное

- Шейдер весит ~290 КБ (gzip) — three.js + r3f. Для боевой версии выбранного
  варианта стоит грузить его после первого кадра страницы.
- Тексты «Обо мне», цены и подпись приглашения — черновик, владелица правит.
- Слоты «Концепт 01/02» — места под будущие концепт-сайты (делаются позже).
- Старые фото-якоря (`/#uslugi` и т. п.) перекидываются на `/ph#…` скриптом
  (`redirectPhotoAnchors` в `src/shared/ui.tsx`) — сработает, когда этот сайт
  встанет в корень.
